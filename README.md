# Sabri Abi

Sabri Abi is a configurable macro program intended for testing games that you own or develop. It is not designed to provide an unfair advantage or to bypass anti-cheat systems. I have tested it on the anti-cheat system of my own Minecraft server.

Use the program only where you have permission and in accordance with the rules of the game, server, and platform. Macro use may be restricted even when testing; this statement does not guarantee that any game or service permits it.

# Sabri Abi (Türkçe)

Sabri Abi, sahibi olduğunuz veya geliştirdiğiniz oyunları denemek için tasarlanmış, ayarlanabilir bir makro programıdır. Haksız avantaj sağlamak veya anti-cheat sistemlerini atlatmak amacıyla tasarlanmamıştır. Kendi Minecraft sunucumun anti-cheat sistemi üzerinde denedim.

Programı yalnızca izin verilen yerlerde ve oyunun, sunucunun ve platformun kurallarına uygun şekilde kullanın. Test amacıyla kullanım da kısıtlanmış olabilir; bu açıklama herhangi bir oyunun veya hizmetin makro kullanımına izin verdiğini garanti etmez.

Yazılımı nasıl kullandığınızdan yalnızca siz sorumlusunuz. Yürürlükteki mevzuatın izin verdiği ölçüde, yazar kullanımından doğabilecek sonuçlarla ilgili sorumluluk kabul etmez.
